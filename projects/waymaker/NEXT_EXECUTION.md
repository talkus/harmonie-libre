**Statut : ACTIF / ACTIONS EXTERNES NON SIMULÉES**

Le projet historique comprend tableau de bord, moteur MVP, système de vente, prospects, pistes de financement et catalogue opérationnel.

## Ce qui peut être préparé sans usurper une action réelle

### Offre minimale vérifiable
- définir un seul service livrable ;
- expliciter entrée, sortie, délai et prix ;
- produire un exemple de livrable ;
- préparer un formulaire de commande ou de demande ;
- séparer clairement démo, commande, paiement et livraison.

### Pipeline commercial
Pour chaque prospect :
- source publique ;
- besoin supposé ;
- preuve du besoin ;
- contact autorisé ;
- statut ;
- prochaine action ;
- résultat réel.

Aucun prospect ne doit être marqué « intéressé », « client » ou « payé » sans preuve.

### Première analyse payée
Le seuil de réalisation est :
1. besoin confirmé ;
2. portée convenue ;
3. prix accepté ;
4. paiement ou engagement attesté ;
5. livrable remis ;
6. retour enregistré.
