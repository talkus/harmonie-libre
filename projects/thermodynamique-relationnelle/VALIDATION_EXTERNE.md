Source retrouvée dans Drive : **`DAA_Four_Laws_Thermodynamics_Manuscript.docx`**.

Le projet revendique notamment des axiomes d'accessibilité/coût, quatre lois relationnelles, des unifications U0→U14.3 et un théorème maître d'accessibilité thermodynamique.

## Plan d'épreuve

1. Extraire chaque loi et chaque théorème avec hypothèses explicites.
2. Classer chaque proposition :
   - définition ;
   - conséquence mathématique ;
   - analogie physique ;
   - loi empirique proposée ;
   - conjecture.
3. Vérifier les limites classiques :
   - équilibre ;
   - non-équilibre ;
   - systèmes ouverts/fermés ;
   - réversibilité/irréversibilité ;
   - changement d'échelle.
4. Chercher les cas où les lois proposées deviennent :
   - identiques à une loi connue ;
   - plus faibles ;
   - contradictoires ;
   - non testables.
5. Construire au moins un exemple numérique reproductible par loi.
6. Définir une prédiction ou discrimination empirique par rapport à une formulation standard.
7. Soumettre les résultats à critique indépendante.

## Critère de réussite

Le projet ne franchit le seuil « validé » que si une proposition distinctive résiste à un test où elle aurait pu échouer.

Pour l'instant : **recherche théorique structurée, pas résultat scientifique établi**.
