# Critères de réussite
- Reproduire la thermodynamique classique d'équilibre dans sa limite pertinente.
- Reproduire les opérations thermiques / Gibbs-préservantes et les monotones connus dans le régime quantique choisi.
- Montrer explicitement que la loi 3 ne fait pas partie des hypothèses cachées du coût.
- Réduire le nombre d'axiomes indépendants par rapport à une simple liste des quatre lois.
- Produire au moins une conséquence quantitative qui n'a pas été utilisée pour choisir les axiomes.
# Critères d'échec
- Si $\mathcal C$ est défini directement comme une fonction divergeant à $T=0$ sans dérivation physique indépendante, l'unification de la loi 3 est circulaire.
- Si le cadre autorise une opération admissible de coût fini atteignant exactement $T=0$, U0 échoue ou le choix d'opérations/coût doit être justifié autrement.
- Si l'entropie relative est utilisée comme entropie universelle malgré les contre-exemples de dépendance au système/résolution déjà trouvés dans nos travaux, la branche échoue méthodologiquement.
# Tests initiaux
T0 : vérifier composition et monotonie sur un modèle thermique fini.
T1 : vérifier conservation énergétique système+bain+batterie.
T2 : vérifier contraction $D(\rho\Vert\gamma)$ sous un canal thermique simple.
T3 : construire un modèle de refroidissement à ressources bornées et vérifier que le coût requis diverge lorsque $T\to0$.
T4 : chercher un contre-exemple où T0–T2 passent mais T3 échoue ; cela démontrerait que le coût apporte une structure indépendante indispensable.
