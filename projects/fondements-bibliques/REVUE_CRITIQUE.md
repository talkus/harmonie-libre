# Fondements bibliques de l'amour — revue critique

**Statut : CORPUS SOURCE RETROUVÉ / REVUE DE PROVENANCE À TERMINER**

Source maîtresse retrouvée : **`02_AMOUR_BIBLIQUE_VERSION_MAITRE_AUDITEE.md`**.

## But

Préserver séparément :

1. le texte biblique source ;
2. la translittération ;
3. la traduction utilisée ;
4. le commentaire lexical ;
5. la dérivation théologique ;
6. l'application au modèle d'alignement.

## Contrôles requis

- vérifier les références exactes pour les 60 passages ;
- distinguer grec/hébreu original, translittération et traduction française ;
- documenter les variantes textuelles quand elles sont pertinentes ;
- ne pas traiter `agapè`, `ahavah`, `hesed`, `philia`, `storgē` comme synonymes parfaits ;
- distinguer sens lexical attesté et interprétation théologique ;
- attribuer toute interprétation confessionnelle au cadre qui la porte ;
- conserver les passages qui compliquent ou limitent l'interprétation proposée.

## Noyau du projet

Le vecteur opérationnel reste :
- aimer Dieu ;
- aimer le prochain comme soi-même ;
- rechercher une universalité qui ne supprime ni vérité, ni liberté, ni altérité.
