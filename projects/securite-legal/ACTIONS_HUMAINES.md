# Sécurité et légal — actes humains requis

**Statut : NON AUTOMATISABLE SANS PARTICIPATION DE MIKAEL**

Ces éléments ne doivent jamais être marqués terminés par une IA seule.

## CAPA-8S-03 — YubiKey
Preuve de clôture requise :
- clé physique possédée ;
- compte cible identifié ;
- clé enregistrée ;
- seconde méthode de récupération vérifiée ;
- test de connexion réussi.

## Microsoft 2FA
Preuve de clôture requise :
- 2FA activée sur le bon compte ;
- méthode principale vérifiée ;
- récupération vérifiée ;
- test de reconnexion effectué.

## CAPA-8S-01 — incorporation / REQ
Preuve de clôture requise :
- décision juridique de structure ;
- dépôt réel auprès de l'autorité compétente ;
- numéro ou document officiel reçu ;
- obligations fiscales/comptables documentées.

## Règle

Une checklist n'est pas une exécution.  
`planned ≠ submitted ≠ accepted ≠ verified`.

Aucune donnée d'identité, information financière ou secret de récupération ne doit être publié dans ce dépôt.
