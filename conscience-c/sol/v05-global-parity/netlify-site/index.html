Méthode et limites

Ce laboratoire exécute le Python source original dans un Web Worker via Pyodide. Les cinq fichiers sont téléchargés depuis un commit GitHub immuable et vérifiés avec SHA-256 avant chargement. En cas d'erreur, aucun vote de remplacement n'est fabriqué.

Ce que cette démonstration ne certifie pas : le seuil de neutralité de 2,5 % n'est pas calibré, les identités des provenances ne sont pas authentifiées, l'algorithme Merkle hérité n'est pas conforme à RFC 6962 et aucune latence garantie n'est établie. Ce site ne déploie pas le noyau Conscience C ni une connexion AEGIS-24.
